# Agentic AI Screening Engine

An enterprise-grade, AI-native application designed to autonomously evaluate engineering candidates against complex Job Descriptions using Local LLM inference. 

Built to demonstrate **Agentic AI workflows, LLM orchestration, and full-stack microservices architecture.**

## System Architecture
* **Client Layer (Next.js, React & Tailwind):** Responsive, state-driven UI for real-time candidate data intake.
* **API Engine (Python & FastAPI):** High-performance, asynchronous REST endpoints to handle AI requests.
* **Inference Layer (Local Ollama):** Localized, privacy-first execution of `Llama-3`, avoiding third-party API latency and ensuring strict HR data compliance.

##  Core Capabilities
- **Agentic Evaluation:** Dynamic system prompting strategy to extract precise match percentages, missing technical keywords, and actionable HR feedback.
- **Privacy-First Processing:** 100% on-device localized data handling without relying on external cloud APIs (OpenAI/Anthropic).
- **Decoupled Architecture:** Strict separation of concerns between the React frontend and Python AI engine.
